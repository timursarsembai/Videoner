Nakikita lang ng mga user na naka-sign in ang mga story at private post, kaya hindi ito makuha ng server ng Videoner. Ngayon, may dalawang solusyon para diyan.

## Mga story sa extension

Dina-download ng [Videoner extension](https://videoner.download/tl/extension) ang **mga Instagram story** direkta sa browser, gamit ang login mo. Magbukas ng story at i-click ang “I-download”: sine-save ang mga video bilang mp4, ang mga larawan bilang jpg.

## I-connect ang account sa bot

Para ma-download din ng bot ang mga story at private post, i-connect dito ang account mo:

1. Mag-sign in sa website ng platform sa browser na may Videoner extension.
2. I-click ang icon ng Videoner at, sa ibaba ng popup, ang **“🔑 I-connect ang iyong … account sa bot”**.
3. Payagan ang access kapag nagtanong ang browser — magpapakita ang extension ng code.
4. Ipadala ang code sa [@VideonerBot](https://t.me/VideonerBot) sa private chat. Valid ang code sa loob ng 10 minuto.

Puwede mong i-connect ang **Instagram, Facebook, YouTube, X, VK at TikTok**. Walang password na kailangan: ang login data lang para sa platform na iyon ang napupunta sa server, naka-encrypt.

Pagkatapos noon, dina-download ng bot ang parehong mga story at private post mula sa mga link mo. Kung magpapadala ka ng link sa profile na may mga story, ipapadala ng bot ang mga kasalukuyang story bilang album; kung hindi iyon gumana, hihingi ito ng link sa isang partikular na story.

Tip: ayaw ng mga platform sa automated na pag-download at puwede nilang i-restrict ang account — mas mabuting mag-connect ng secondary account, hindi ang main account mo.

## Para sa mga grupo

Para ma-download ng bot ang mga story para sa buong grupo, ipadala ang **/connect CODE** sa grupong iyon. Kung sino ang puwedeng mag-connect ng account — mga admin lang o lahat — ay itinatakda sa /settings. Kung walang naka-connect na account para sa grupo, dina-download ng bot ang link mo gamit ang personal mong koneksyon.

## Pamamahala ng mga koneksyon

- **/accounts** — listahan ng mga koneksyon mo: puwede mong alisin ang isa o lahat nang sabay-sabay.
- Binubuksan ng button na **“Mga koneksyon ko sa bot”** sa extension ang parehong listahan.
- Inaalis ng button na **“Bawiin ang access sa cookies”** sa extension ang pahintulot — hindi na binabasa ng extension ang login data. Nananatili sa bot ang mga account na na-connect mo na; maaalis mo ang mga ito gamit ang /accounts.
