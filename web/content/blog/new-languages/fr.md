Videoner est désormais disponible en **14 langues**. À l’anglais, l’espagnol, le russe, l’ukrainien, le kazakh et l’arabe s’ajoutent huit nouvelles langues :

- **Chinois** (simplifié) — [videoner.download/zh](https://videoner.download/zh)
- **Hindi** — [videoner.download/hi](https://videoner.download/hi)
- **Indonésien** — [videoner.download/id](https://videoner.download/id)
- **Swahili** — [videoner.download/sw](https://videoner.download/sw)
- **Allemand** — [videoner.download/de](https://videoner.download/de)
- **Français** — [videoner.download/fr](https://videoner.download/fr)
- **Italien** — [videoner.download/it](https://videoner.download/it)
- **Portugais** (brésilien) — [videoner.download/pt](https://videoner.download/pt)

## Ce qui est traduit

- **Le site** — toutes les pages, les articles du blog et les documents juridiques.
- **Le bot** — tous les messages, les boutons et le menu des commandes. Si votre Telegram est réglé sur l’une de ces langues, le bot vous répond automatiquement dans cette langue.
- **L’extension de navigateur** — la fenêtre de l’extension, le bouton « Télécharger » sur les pages vidéo et les messages d’erreur.

## Comment choisir la langue

- Sur le site — le sélecteur de langue dans le menu du haut.
- Dans le bot — `/language` ; dans un groupe — `/settings`.
- Dans l’extension — la liste des langues dans sa fenêtre.
