Videoner 브라우저 확장 프로그램에 새로운 기능 두 가지가 생겼어요. 다운로드 기록, 그리고 Mozilla 공식 카탈로그에서 Firefox에 설치하는 기능이에요.

## 다운로드 기록

확장 프로그램 창의 언어 선택 옆에 시계 버튼이 생겼어요. 이 버튼을 누르면 최근 **30일** 동안 확장 프로그램으로 다운로드한 모든 항목의 목록이 열려요.

- 동영상 **제목** — 클릭하면 동영상 페이지를 다시 열 수 있어요.
- 다운로드한 **날짜와 시간**.
- 오디오만 다운로드했다면 **MP3** 표시.

같은 동영상을 다시 다운로드하면 해당 항목이 맨 위로 올라갈 뿐이에요. '기록 삭제' 버튼을 누르면 목록 전체가 지워져요.

기록은 **회원님의 브라우저에만** 저장돼요. Videoner 서버로 전송되지 않으며, 회원님 말고는 아무도 볼 수 없어요.

## Firefox: Mozilla 부가 기능 카탈로그

이제 [Mozilla 부가 기능 카탈로그](https://addons.mozilla.org/firefox/addon/videoner-video-downloader/)에서 Videoner를 만날 수 있어요. [확장 프로그램 페이지](https://videoner.download/ko/extension)의 Firefox 버튼을 누르면 그곳으로 이동해요. 'Firefox에 추가'를 클릭하면 끝이에요. 업데이트는 Firefox가 알아서 설치해요.

이미 저희 사이트에서 확장 프로그램을 설치했다면 따로 할 일은 없어요. 다음 업데이트 확인 때 Firefox가 모든 설정을 그대로 유지한 채 카탈로그 버전으로 알아서 바꿔요.

## 업데이트 방법

- **Firefox** — 하루 안에 알아서 업데이트돼요.
- **Chrome, Yandex Browser, Edge, Opera** — Videoner 아이콘에 NEW 표시가 나타나요. [확장 프로그램 페이지](https://videoner.download/ko/extension#update)에서 새 압축 파일을 다운로드한 다음, 같은 폴더에 압축을 풀어 파일을 덮어쓰세요.
