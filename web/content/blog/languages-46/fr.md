Videoner est désormais disponible en **46 langues**. 11 nouvelles langues s’ajoutent :

- **Afghanistan et Kurdistan :** pachto — [/ps](https://videoner.download/ps), kurde (sorani) — [/ckb](https://videoner.download/ckb), kurde (kurmandji) — [/ku](https://videoner.download/ku)
- **Asie centrale et région de la Volga :** ouïghour — [/ug](https://videoner.download/ug), turkmène — [/tk](https://videoner.download/tk), tatar — [/tt](https://videoner.download/tt)
- **Balkans :** albanais — [/sq](https://videoner.download/sq), bosnien — [/bs](https://videoner.download/bs)
- **Caucase :** tchétchène — [/ce](https://videoner.download/ce), ingouche — [/inh](https://videoner.download/inh), avar — [/av](https://videoner.download/av)

## Ce qui est traduit

- **Le site** — toutes les pages, les articles du blog et les documents juridiques. Le pachto, le sorani et l’ouïghour s’affichent de droite à gauche.
- **Le bot** — tous les messages, les boutons et le menu des commandes. Si votre Telegram est réglé sur l’une de ces langues, le bot vous répond automatiquement dans cette langue.
- **L’extension de navigateur** — la fenêtre de l’extension, le bouton « Télécharger » sur les pages vidéo et les messages d’erreur.

## Comment choisir la langue

- Sur le site — le sélecteur de langue dans le menu du haut.
- Dans le bot — `/language` ; dans un groupe — `/settings`.
- Dans l’extension — la liste des langues dans sa fenêtre.

Partout, les langues sont affichées dans le même ordre : selon le nom de chaque langue dans cette langue même.
