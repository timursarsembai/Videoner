Videoner браузера расширене шиъ керда хӀама я: чуяккхара истори а Mozilla официальни каталога тӀара Firefox-е дӀахӀоттаяр а.

## Чуяккхара истори

Расширени кора чу, мотт хьаржачунна уллув, сахьат долла кнопка гучаяьннай. Цо хьаелл тӀехьарча **30 дийнахь** расширени чухьа Шо чуяьккха массе хӀама долла список:

- видео **цӀи** — тӀатоӀал, цун оагӀув юха хьаелла;
- чуяккхара **терахь а хан а**;
- **MP3** белгало, аудио мара чуяьккхаяле.

Цу видео юха чуяьккхача — дӀаяздар список лакхе хьалагӀоттаргья. «Истори цӀанъе» кнопко деррига список дӀаяккх.

Истори **Шун браузере мара** латтац: Videoner сервере из дахийтац, Шо мара цхьаккханна из гуш яц.

## Firefox: Mozilla дополненей каталог

Videoner хӀанз [Mozilla дополненей каталоге](https://addons.mozilla.org/firefox/addon/videoner-video-downloader/) я. [Расширени оагӀон тӀа](https://videoner.download/inh/extension) йола Firefox кнопко цига дуг — «Добавить в Firefox» тӀа таӀадел, кхы хӀама эшац. Карладаккхараш Firefox-а ше дӀахӀоттаду.

Шо расширени тха сайта тӀара дӀахӀоттаяьй елча, хӀама де эшац: карладаккхараш тӀехьагӀа тохкача, Firefox-а ше из каталога версе дехьаяккхаргья, Шун массе настройкашца.

## Мишта карлаяккха

- **Firefox** — цхьа ди-буса чу ше карлаяргья.
- **Chrome, Яндекс Браузер, Edge, Opera** — Videoner значок тӀа NEW белгало гучаялаш я. [Расширени оагӀон тӀа](https://videoner.download/inh/extension#update) керда архив чуяккхал, из цу папке распаковать дел, файлаш хувцаш.
