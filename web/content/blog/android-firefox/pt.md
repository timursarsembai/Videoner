Para o bot baixar stories e posts privados do Instagram, você precisa conectar sua conta a ele. Até agora, isso exigia um computador com a extensão do Videoner. Agora dá para conectar direto do seu celular **Android**.

## O que você precisa

- Um celular Android.
- O navegador **Firefox**, da Google Play: o Chrome para celular não aceita extensões, mas o Firefox aceita.
- O complemento **Cookie-Editor** para Firefox.

## Como conectar

1. Instale o Firefox e entre na sua conta do instagram.com por ele.
2. Menu do Firefox (⋮) → “Extensões” → encontre e instale o **Cookie-Editor**.
3. Abra o instagram.com e depois menu (⋮) → “Extensões” → Cookie-Editor.
4. Toque em **Export** e escolha o formato **Netscape** — seus dados de login serão copiados para a área de transferência.
5. Abra o [@VideonerBot](https://t.me/VideonerBot) em uma conversa privada e cole o texto copiado como uma mensagem normal.

O bot vai responder que a conta foi conectada. Agora envie para ele links de stories — ele vai baixá-los usando o seu login. Para ver e desconectar a conexão, use o comando **/accounts**.

## Importante

- Esse texto dá acesso à sua conta do Instagram. Envie **somente para o bot, em conversa privada** — não em um grupo nem para outras pessoas.
- O bot guarda apenas os dados de login da plataforma de que precisa, e os armazena criptografados.
- As plataformas não gostam de downloads automáticos e podem restringir a conta, então é melhor conectar uma conta secundária em vez da principal.
- Assim você conecta uma conta só para você. Para conectar uma conta para um grupo inteiro, use a [extensão no computador](https://videoner.download/pt/extension) e o comando /connect.

## E no iPhone?

No iPhone isso não funciona: o Safari não permite exportar os dados de login. Lá, é mais fácil conectar a conta uma vez pelo computador, com a extensão do Videoner.
