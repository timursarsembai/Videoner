Sebelumnya, dari postingan yang berisi beberapa file Anda hanya bisa mengunduh satu video. Kini Videoner mengambil seluruh postingan.

## Carousel dan foto

- **Setiap file dalam postingan** diunduh: beberapa video, beberapa foto, atau campuran keduanya.
- **Foto** disimpan sebagai JPEG biasa dalam ukuran terbaik yang tersedia.
- Jika postingan hanya berisi foto, tidak ada kualitas yang perlu dipilih — Anda mendapat satu tombol dengan file aslinya.

**Di bot**, carousel dikirim sebagai album. Telegram mengizinkan maksimal 10 file per album, jadi postingan besar datang dalam beberapa album. Postingan dengan satu foto dikirim sebagai foto, bukan video.

**Di situs web**, setiap file dalam postingan ditampilkan terpisah dengan tombolnya sendiri, dan tombol "Unduh semua" menyimpannya satu per satu.

## Threads

Kami menambahkan **Threads**: kirim tautan ke sebuah postingan, dan Videoner akan mengunduh video dan foto di dalamnya. Tautan pendek dari tombol "Bagikan" di aplikasi seluler Threads juga berfungsi.

## Keterangan file

Bot kini menambahkan keterangan pada file yang dikirimnya: judul dan tautan ke sumber aslinya. Dengan begitu, mudah mengetahui asal sebuah video di chat Anda.
