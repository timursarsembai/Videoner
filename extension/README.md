# Расширение Videoner для браузера

Скачивает видео со страницы, где его смотрят: кнопка «Скачать» в углу
страницы видео (или клик по значку Videoner в панели браузера) → выбор
качества → файл в «Загрузках». Работает в Chrome, Яндекс Браузере и Edge.

Кнопка появляется только на странице конкретного видео или поста, не на
главной и не в ленте. Крестик на ней прячет её до перехода к другому видео.

TikTok и Threads браузер скачивает сам, если на странице есть готовый mp4
(`page-media.js`), — без очереди на сервере; сервер получает только отчёт для
статистики (`POST /api/ext/download/report`). Не вышло — тот же ролик
автоматически качается через сервер. Остальные площадки, а также другие
качества и звук, скачивает сервер Videoner, как для сайта и бота. Расширение ходит в API через
`https://videoner.download/api/ext/*` (без капчи, с лимитами по IP — см.
`web/app/api/ext/[...path]/route.ts`), а за ходом скачивания следит по
публичному `/download/<id>/status`. Скачивания из расширения видны на
дашборде с источником «Расширение».

## Установка вручную

В магазин расширений Videoner не выкладывается — ставится из архива.

1. Распакуйте архив `videoner-extension-<версия>.zip` в постоянное место
   (не во временную папку: браузер читает расширение оттуда при каждом
   запуске). Получится папка `videoner-extension`.
2. Откройте страницу расширений: `chrome://extensions` в Chrome,
   `browser://extensions` в Яндекс Браузере, `edge://extensions` в Edge.
3. Включите «Режим разработчика» (переключатель вверху справа или слева
   внизу — зависит от браузера).
4. Нажмите «Загрузить распакованное расширение» и выберите папку
   `videoner-extension`.
5. Браузер предупредит, что расширению нужен доступ к страницам YouTube,
   TikTok, Instagram и других площадок — без него не показать кнопку
   «Скачать» на странице видео.
6. Закрепите значок Videoner на панели (значок пазла → булавка).

Chrome может при запуске предлагать отключить расширения в режиме
разработчика — это предупреждение для всех расширений не из магазина,
Videoner работает дальше.

### Обновление

Распакуйте новый архив поверх той же папки и нажмите «Обновить» (стрелка по
кругу) на карточке Videoner на странице расширений.

### Сборка архива

`scripts/pack-extension.sh` → `dist/videoner-extension-<версия>.zip`. Версию
перед раздачей поднимите в `manifest.json`.

## Устройство

- `popup.html`, `popup.js`, `popup.css` — окошко: качества, прогресс, ошибки.
- `background.js` — запускает скачивание, следит за ним и сохраняет файл в
  «Загрузки»; работает, даже когда окошко закрыто.
- `shared.js` — адрес API, тексты на русском и английском, перевод ошибок.
- `content.js`, `video-pages.js` — кнопка на страницах площадок; по клику
  открывает то же окошко в рамке (`popup.html?embed=1&url=…`).
