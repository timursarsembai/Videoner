Videoner est désormais disponible en **25 langues**. À l’anglais, l’espagnol, le russe, l’ukrainien, le kazakh et l’arabe s’ajoutent 19 nouvelles langues :

- **Asiatiques :** chinois (simplifié) — [/zh](https://videoner.download/zh), hindi — [/hi](https://videoner.download/hi), bengali — [/bn](https://videoner.download/bn), ourdou — [/ur](https://videoner.download/ur), japonais — [/ja](https://videoner.download/ja), coréen — [/ko](https://videoner.download/ko), thaï — [/th](https://videoner.download/th), vietnamien — [/vi](https://videoner.download/vi), indonésien — [/id](https://videoner.download/id), tagalog — [/tl](https://videoner.download/tl)
- **Asie centrale et Moyen-Orient :** ouzbek — [/uz](https://videoner.download/uz), turc — [/tr](https://videoner.download/tr), persan — [/fa](https://videoner.download/fa)
- **Européennes :** allemand — [/de](https://videoner.download/de), français — [/fr](https://videoner.download/fr), italien — [/it](https://videoner.download/it), portugais (brésilien) — [/pt](https://videoner.download/pt), polonais — [/pl](https://videoner.download/pl)
- **Africaine :** swahili — [/sw](https://videoner.download/sw)

Jusqu’ici, l’espagnol n’était disponible que sur le site — désormais, le bot et l’extension le parlent aussi.

## Ce qui est traduit

- **Le site** — toutes les pages, les articles du blog et les documents juridiques. L’arabe, le persan et l’ourdou s’affichent de droite à gauche.
- **Le bot** — tous les messages, les boutons et le menu des commandes. Si votre Telegram est réglé sur l’une de ces langues, le bot vous répond automatiquement dans cette langue.
- **L’extension de navigateur** — la fenêtre de l’extension, le bouton « Télécharger » sur les pages vidéo et les messages d’erreur.

## Comment choisir la langue

- Sur le site — le sélecteur de langue dans le menu du haut.
- Dans le bot — `/language` ; dans un groupe — `/settings`.
- Dans l’extension — la liste des langues dans sa fenêtre.

Les trois affichent désormais les langues dans le même ordre : selon le nom de chaque langue dans cette langue même.
