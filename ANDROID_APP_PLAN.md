# Videoner для Android — план

Составлено 30.10.2026. Код ещё не начат: план утверждён владельцем, работа идёт
по этапам ниже, статус — в начале каждого этапа.

## Зачем

Бот @VideonerBot работает не у всех: в РФ Telegram блокируют, а это большая
часть аудитории, и Telegram есть не у каждого. Сайт на телефоне неудобен:
ссылку нужно копировать, файл открывается в браузере. Приложение принимает
ссылку прямо из «Поделиться» и сохраняет файл в галерею.

## Решения владельца

- **React Native** (30.10.2026). Минус по сравнению с Kotlin — больший
  размер APK, поэтому собираем отдельные APK под архитектуры процессора (см.
  «Сборка»), а не один универсальный.
- **Название и значок — как у расширения:** «Videoner», значок из
  `web/public/images/logo.svg`.
- **Не в Google Play.** Правила Play запрещают приложения, которые качают с
  YouTube, — независимо от того, что качает сервер. Раздаём APK со своего
  сайта, ссылки — в боте, как с расширениями. Вариант для Play без YouTube —
  возможный этап потом.

## Что умеет первая версия

1. **Ссылка на вход:** «Поделиться → Videoner» из YouTube, TikTok, Instagram,
   браузера и любого другого приложения; либо вставка вручную (при открытии
   приложение предлагает ссылку из буфера обмена).
2. **Выбор:** превью и название ролика, качества с размером, «только звук
   (mp3)», субтитры — то же, что окошко расширения.
3. **Скачивание:** ролик качает и склеивает сервер Videoner (как для бота и
   сайта), телефон получает один готовый файл. Прогресс — в уведомлении,
   скачивание идёт при свёрнутом приложении; файл попадает в «Загрузки» и
   виден в галерее.
4. **Языки:** русский, английский, испанский (как на сайте).
5. **Обновления:** приложение раз в сутки спрашивает у сайта последнюю версию
   и предлагает обновиться (скачать APK → установщик Android).
6. **Android 7 и новее** (minSdk 24).

Чего нет в первой версии: скачивания с телефона под входом человека
(закрытые видео Instagram/Facebook — расширение умеет, приложению нужен свой
вход через WebView), уроков GetCourse, истории, аккаунта и подписки.

## Устройство

- **Проект:** `android/` в корне репозитория. Expo (bare workflow после
  `expo prebuild`) — готовые модули для «Поделиться», уведомлений и файлов,
  но сборка локальная, без облака Expo (EAS).
- **Общение с сервером:** те же запросы, что у расширения
  (`extension/shared.js`, `background.js`): `POST /info`,
  `POST /download/video|audio|subtitles`, статус
  `/download/<id>/status`, файл `/download/<имя>`.
- **Скачивание файла:** системный DownloadManager Android (модуль
  `react-native-blob-util`): сам показывает уведомление с прогрессом,
  переживает закрытие приложения, кладёт файл в «Загрузки». Ожидание на
  сервере (очередь, склейка) — в уведомлении приложения.
- **«Поделиться»:** intent-filter `ACTION_SEND` text/plain (модуль
  `expo-share-intent` или аналог); из текста берём первую ссылку.
- **Сборка:** в Docker на этом сервере (образ с Android SDK, JDK 17, Node 22),
  скрипт `scripts/build-android.sh` по образцу `pack-extension.sh`. Hermes
  включён; APK отдельно для `arm64-v8a` (почти все телефоны) и
  `armeabi-v7a` (старые) — ожидаемо 15–25 МБ каждый.
- **Ключ подписи:** создаётся один раз, хранится в Infisical (проект
  videoner) и копией у владельца офлайн. Потеря ключа = установленные
  приложения больше не обновятся, только переустановка.

## Этапы

### 1. Сервер — [не начат]

- Вход `web/app/api/app/[...path]/route.ts` по образцу
  `web/app/api/ext/[...path]/route.ts`: без капчи, лимиты по IP (свои
  переменные `APP_RATE_LIMIT`, `APP_INFO_RATE_LIMIT`). Проверки Origin у
  приложения нет — отличаем по заголовку `X-Videoner-App: <версия>`; подделать
  его легко, это та же осознанная граница, что у расширения (защита —
  лимиты по IP и суточный лимит трафика YouTube).
- Значение `APP` в `enum DownloadSource` (`server/prisma/schema.prisma`,
  миграция) — отдельная строка «Приложение» на дашборде.
- Файл версий `web/public/app/android-updates.json`: последняя версия,
  versionCode, ссылки на APK, sha256, минимальная поддерживаемая версия
  (чтобы при поломке API попросить обновиться).

### 2. Приложение — [не начат]

Экраны: ввод/приём ссылки → выбор формата → прогресс → готово (открыть файл,
поделиться). Тексты ошибок — те же, что у расширения (`shared.js`). Проверка
обновлений. Значок: adaptive icon из `logo.svg`.

### 3. Распространение — [не начат]

- Страница `videoner.download/app` (ru/en/es): кнопка «Скачать APK» отдаёт
  вариант arm64 (браузер не сообщает архитектуру процессора надёжно), ниже —
  ссылка на вариант для старых телефонов; инструкция по установке из файла с
  картинками: разрешить установку из браузера/Telegram, предупреждение Play
  Protect.
- Ссылки на сайте: в шапке/подвале и на странице расширения для телефонов
  (там сейчас нечего предложить мобильным).
- Бот: команда `/app`, строка в `/start` и в описании бота рядом с
  расширением — всем (платформу пользователя бот не знает).
- Статистика: скачивания APK и активные установки (приложение шлёт версию в
  заголовке — видно на дашборде).

### 4. Проверка — [не начат]

Эмулятор здесь (Android 7, 10, 14, 15). Владелец — 2–3 реальных телефона,
обязательно один старый и Xiaomi/Redmi (MIUI/HyperOS строже всех к фоновой
работе и установке из файлов). Сценарии: «Поделиться» из YouTube/TikTok/
Instagram, долгий ролик при свёрнутом приложении, только звук, субтитры,
обновление с прошлой версии.

## Риски

- **Блокировка сайта в РФ.** Приложение ходит на videoner.download; если
  заблокируют домен, перестанет работать и приложение. Запасной адрес,
  который приложение пробует само, заложить в коде сразу; второй домен —
  решение владельца, когда понадобится.
- **Проверка разработчиков Google.** С 30.09.2026 в Бразилии, Индонезии,
  Сингапуре и Таиланде, в 2027 — во всём мире: на сертифицированных
  телефонах приложение от неподтверждённого разработчика ставится только
  через «продвинутый способ» (однократно ждать 24 часа и несколько
  подтверждений). До 2027 зарегистрироваться в Android Developer Console и
  подтвердить личность ($25) — это не публикация в Google Play. Телефонов без
  сервисов Google (Huawei и др.) не касается. Источник:
  https://developer.android.com/developer-verification
- **Play Protect** может предупреждать при установке незнакомого приложения —
  инструкция на странице `/app`.
- **Размер APK** у React Native больше, чем у нативного; на медленном
  интернете это заметно — отсюда отдельные APK по архитектурам.
