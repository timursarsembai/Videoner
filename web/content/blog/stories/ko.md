스토리와 비공개 게시물은 로그인한 사용자에게만 보이기 때문에 Videoner 서버는 가져올 수 없어요. 이제 이 문제를 해결하는 방법이 두 가지 생겼어요.

## 확장 프로그램으로 스토리 다운로드

[Videoner 확장 프로그램](https://videoner.download/ko/extension)은 회원님의 로그인을 이용해 브라우저에서 바로 **Instagram 스토리**를 다운로드해요. 스토리를 열고 "다운로드"를 누르면 동영상은 mp4로, 사진은 jpg로 저장돼요.

## 봇에 계정 연결하기

봇도 스토리와 비공개 게시물을 다운로드할 수 있도록 계정을 봇에 연결하세요.

1. Videoner 확장 프로그램이 설치된 브라우저에서 플랫폼 웹사이트에 로그인하세요.
2. Videoner 아이콘을 누르고, 팝업 아래쪽의 **"🔑 내 … 계정을 봇에 연결"**을 누르세요.
3. 브라우저가 권한을 요청하면 허용하세요. 확장 프로그램이 코드를 보여 드려요.
4. 개인 채팅에서 [@VideonerBot](https://t.me/VideonerBot)에 코드를 보내세요. 코드는 10분 동안 유효해요.

**Instagram, Facebook, YouTube, X, VK, TikTok**을 연결할 수 있어요. 비밀번호는 필요 없어요. 해당 플랫폼의 로그인 데이터만 암호화되어 서버로 전송돼요.

그다음부터는 회원님이 보낸 링크의 스토리와 비공개 게시물을 봇이 다운로드해요. 스토리가 있는 프로필 링크를 보내면 봇이 현재 스토리를 앨범으로 보내 드려요. 그게 안 되면 특정 스토리의 링크를 요청해요.

팁: 플랫폼은 자동 다운로드를 좋아하지 않아서 계정을 제한할 수 있어요. 주 계정이 아니라 보조 계정을 연결하는 편이 좋아요.

## 그룹용

봇이 그룹 전체를 위해 스토리를 다운로드하게 하려면, 그 그룹에서 **/connect CODE**를 보내세요. 누가 계정을 연결할 수 있는지(관리자만 또는 모두)는 /settings에서 정해요. 그룹에 연결된 계정이 없으면 봇은 회원님의 개인 연결로 회원님의 링크를 다운로드해요.

## 연결 관리

- **/accounts** — 회원님의 연결 목록이에요. 하나씩 또는 한꺼번에 모두 삭제할 수 있어요.
- 확장 프로그램의 **"봇에 연결된 내 계정"** 버튼을 누르면 같은 목록이 열려요.
- 확장 프로그램의 **"쿠키 접근 권한 취소"** 버튼을 누르면 권한이 삭제되어, 확장 프로그램이 더 이상 로그인 데이터를 읽지 않아요. 이미 연결한 계정은 봇에 남아 있으니 /accounts에서 삭제할 수 있어요.
