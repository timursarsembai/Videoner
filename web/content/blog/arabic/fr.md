---
Videoner est désormais disponible en **arabe** — la sixième langue après l’anglais, l’espagnol, le russe, l’ukrainien et le kazakh.

## Ce qui est traduit

- **Le site** — toutes les pages, les articles du blog et les documents juridiques. La version arabe se trouve à l’adresse [videoner.download/ar](https://videoner.download/ar), et la page se lit de droite à gauche, comme les lecteurs arabophones en ont l’habitude.
- **Le bot** — tous les messages, les boutons et le menu des commandes. Si votre Telegram est en arabe, le bot vous répond automatiquement en arabe. Vous pouvez changer de langue avec `/language`.
- **L’extension de navigateur** — la fenêtre de l’extension, le bouton « Télécharger » sur les pages vidéo et les messages d’erreur. La langue se choisit dans la fenêtre de l’extension.

## Comment choisir la langue

- Sur le site — le sélecteur de langue dans le menu du haut.
- Dans le bot — `/language` ; dans un groupe — `/settings`.
- Dans l’extension — la liste des langues dans sa fenêtre.
