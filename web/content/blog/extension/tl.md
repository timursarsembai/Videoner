Kung madalas kang mag-download ng video sa computer, magagawa mo na ito nang hindi kinokopya ang mga link. Kilalanin ang Videoner browser extension.

## Paano ito gumagana

- May lumalabas na button na **“I-download”** sa sulok ng page ng video o post. I-click ito, pumili ng quality, at mase-save ang file sa folder na “Downloads” mo.
- Ang parehong popup ay bumubukas din mula sa icon ng Videoner sa toolbar ng browser.
- Gaya sa website, puwede kang mag-download ng audio lang, at ng subtitles para sa YouTube.
- Puwede mong isara agad ang popup: tuloy-tuloy ang pag-download nang mag-isa.

Sa page lang ng isang partikular na video lumalabas ang button, hindi sa feed. Itinatago ng ekis dito ang button hanggang sa susunod na video.

## Pag-download gamit ang sarili mong login

Dina-download ng extension ang **Instagram, Facebook, TikTok at Threads** direkta sa browser — bilang ikaw, sa platform. Ibig sabihin, kaya nitong i-download ang mga private post na nakikita mo sa account mo, pati ang mga video na hindi ibibigay ng platform sa server namin. Hindi kailanman hinihingi ng extension ang password mo, at hindi kailanman napupunta sa server ang login mo.

Kung hindi ibinigay ng platform ang isang video sa bot o sa website, imumungkahi na nilang i-download ito gamit ang extension — at bibigyan ka ng link.

Para sa ibang platform, pati sa ibang quality at audio, nagda-download ang extension sa pamamagitan ng server ng Videoner, gaya ng website at ng bot.

## Paano i-install

Gumagana ang extension sa **Chrome, Yandex Browser, Edge, Opera** at iba pang browser na batay sa Chromium — sa computer.

1. Buksan ang [page ng extension](https://videoner.download/tl/extension) at i-download ang archive.
2. I-unzip ito sa isang permanenteng folder — magkakaroon ka ng folder na videoner-extension.
3. Buksan ang page ng mga extension: chrome://extensions (edge://extensions sa Edge).
4. I-on ang “Developer mode”.
5. I-click ang “Load unpacked” at piliin ang folder na videoner-extension.

I-pin ang icon ng Videoner sa toolbar ng browser para laging madaling maabot.

Hindi gumagana ang mga extension sa phone — doon, gamitin ang website na [videoner.download](https://videoner.download/tl) o ang bot na [@VideonerBot](https://t.me/VideonerBot).
