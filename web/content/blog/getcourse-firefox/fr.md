Deux grandes mises à jour de l’extension Videoner.

## Les cours GetCourse

L’extension télécharge désormais les vidéos des cours des écoles en ligne hébergées sur GetCourse.

1. Connectez-vous à votre école et ouvrez un cours.
2. Un bouton **« Télécharger »** apparaît dans le coin supérieur droit du lecteur.
3. Si le cours contient plusieurs vidéos, cliquez sur l’icône Videoner dans la barre d’outils : elle les affichera toutes.

Votre navigateur télécharge lui-même le cours et l’assemble en un fichier **mp4** ordinaire. Le fichier ne passe pas par notre serveur : vous pouvez donc télécharger tout ce que vous voyez une fois connecté à votre école. Si le téléchargement dans le navigateur échoue, le serveur Videoner téléchargera le même cours dans la même qualité.

À savoir : le cours est assemblé dans la mémoire du navigateur et enregistré d’un seul coup à la fin, donc une longue vidéo en haute qualité prendra un peu de temps.

## Version pour Firefox

L’extension est désormais disponible pour **Mozilla Firefox 128 et versions ultérieures**. Elle fait tout ce que fait l’autre version : le bouton « Télécharger » sur la page de la vidéo, le téléchargement avec votre connexion et les cours GetCourse.

Installation en un clic :

1. Ouvrez la [page de l’extension](https://videoner.download/fr/extension) dans Firefox et cliquez sur le bouton Firefox.
2. Firefox vous demande s’il doit autoriser l’installation depuis videoner.download : cliquez sur « Continuer l’installation ».
3. Dans la fenêtre « Ajouter Videoner ? », cliquez sur « Ajouter ».

L’extension est signée par Mozilla, et Firefox installe les mises à jour tout seul.

La page de l’extension comporte désormais deux boutons — l’un pour les navigateurs de type Chrome, l’autre pour Firefox — et celui de votre navigateur est mis en avant.

## L’extension dans le bot

Le bot [@VideonerBot](https://t.me/VideonerBot) dispose désormais d’une commande **/extension** : elle présente l’extension et vous donne un lien pour l’installer.
