Dua pembaruan besar untuk ekstensi Videoner.

## Pelajaran GetCourse

Ekstensi kini mengunduh video pelajaran dari sekolah online di GetCourse.

1. Masuk ke sekolah Anda dan buka sebuah pelajaran.
2. Tombol **"Unduh"** muncul di sudut kanan atas pemutar.
3. Jika pelajaran berisi beberapa video, klik ikon Videoner di toolbar — semuanya akan tercantum di sana.

Browser Anda sendiri yang mengunduh pelajaran dan merakitnya menjadi file **mp4** biasa. File tidak melewati server kami, jadi Anda bisa mengunduh apa pun yang terlihat saat Anda masuk ke sekolah. Jika unduhan lewat browser gagal, server Videoner akan mengunduh pelajaran yang sama dalam kualitas yang sama.

Perlu diingat: pelajaran dirakit di memori browser dan disimpan sekaligus di akhir, jadi video panjang dalam kualitas tinggi akan memerlukan waktu.

## Versi Firefox

Ekstensi kini tersedia untuk **Mozilla Firefox 128 dan yang lebih baru**. Versi ini melakukan semua yang dilakukan versi lain: tombol "Unduh" di halaman video, unduhan dengan login Anda, dan pelajaran GetCourse.

Pemasangan sekali klik:

1. Buka [halaman ekstensi](https://videoner.download/id/extension) di Firefox dan klik tombol Firefox.
2. Firefox akan bertanya apakah mengizinkan pemasangan dari videoner.download — klik "Lanjutkan ke Pemasangan" (Continue to Installation).
3. Pada pertanyaan "Tambahkan Videoner?" (Add Videoner?), klik "Tambahkan" (Add).

Ekstensi ini ditandatangani oleh Mozilla, dan Firefox memasang pembaruannya sendiri.

Halaman ekstensi kini memiliki dua tombol — satu untuk browser mirip Chrome dan satu untuk Firefox — dengan browser Anda disorot.

## Ekstensi di bot

Bot [@VideonerBot](https://t.me/VideonerBot) kini memiliki perintah **/extension** — perintah ini menjelaskan tentang ekstensi dan memberikan tautan pemasangan.
