# Расширение Videoner для браузера

Скачивает видео со страницы, где его смотрят: кнопка «Скачать» в углу
страницы видео (или клик по значку Videoner в панели браузера) → выбор
качества → файл в «Загрузках». Работает в Chrome, Яндекс Браузере и Edge.

Кнопка появляется только на странице конкретного видео или поста, не на
главной и не в ленте. Крестик на ней прячет её до перехода к другому видео.

Скачивает сервер Videoner, как для сайта и бота. Расширение ходит в API через
`https://videoner.download/api/ext/*` (без капчи, с лимитами по IP — см.
`web/app/api/ext/[...path]/route.ts`), а за ходом скачивания следит по
публичному `/download/<id>/status`. Скачивания из расширения видны на
дашборде с источником «Расширение».

## Установка вручную

1. Скачайте папку `extension/` (или распакуйте архив с ней).
2. Откройте `chrome://extensions` (в Яндекс Браузере — `browser://extensions`,
   в Edge — `edge://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.
5. Закрепите значок Videoner на панели (значок пазла → булавка).

## Устройство

- `popup.html`, `popup.js`, `popup.css` — окошко: качества, прогресс, ошибки.
- `background.js` — запускает скачивание, следит за ним и сохраняет файл в
  «Загрузки»; работает, даже когда окошко закрыто.
- `shared.js` — адрес API, тексты на русском и английском, перевод ошибок.
- `content.js`, `video-pages.js` — кнопка на страницах площадок; по клику
  открывает то же окошко в рамке (`popup.html?embed=1&url=…`).
