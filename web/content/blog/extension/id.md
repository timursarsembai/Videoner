Jika Anda sering mengunduh video di komputer, kini Anda bisa melakukannya tanpa menyalin tautan. Perkenalkan ekstensi browser Videoner.

## Cara kerjanya

- Tombol **"Unduh"** muncul di sudut halaman video atau postingan. Klik tombolnya, pilih kualitas, dan file akan disimpan ke folder "Unduhan".
- Jendela yang sama terbuka dari ikon Videoner di toolbar browser.
- Seperti di situs web, Anda bisa mengunduh audionya saja, juga subtitel untuk YouTube.
- Anda bisa langsung menutup jendelanya: unduhan tetap berjalan dengan sendirinya.

Tombol hanya muncul di halaman video tertentu, tidak di feed. Tanda silang pada tombol menyembunyikannya hingga video berikutnya.

## Mengunduh dengan login Anda

Ekstensi mengunduh **Instagram, Facebook, TikTok, dan Threads** langsung di browser — atas nama Anda di platform tersebut. Artinya, ekstensi bisa mengunduh postingan privat yang terlihat di akun Anda, juga video yang tidak mau diberikan platform ke server kami. Ekstensi tidak pernah meminta kata sandi Anda, dan login Anda tidak pernah dikirim ke server.

Jika platform tidak memberikan video ke bot atau situs web, keduanya kini akan menyarankan untuk mengunduhnya dengan ekstensi — dan memberikan tautannya.

Untuk platform lain, serta kualitas lain dan audio, ekstensi mengunduh melalui server Videoner, sama seperti situs web dan bot.

## Cara memasang

Ekstensi berfungsi di **Chrome, Yandex Browser, Edge, Opera**, dan browser lain berbasis Chromium — di komputer.

1. Buka [halaman ekstensi](https://videoner.download/id/extension) dan unduh arsipnya.
2. Ekstrak ke folder permanen — Anda akan mendapatkan folder videoner-extension.
3. Buka halaman ekstensi browser: chrome://extensions (edge://extensions di Edge).
4. Aktifkan "Mode developer" (Developer mode).
5. Klik "Muat yang belum dibuka" (Load unpacked) dan pilih folder videoner-extension.

Sematkan ikon Videoner ke toolbar browser agar selalu mudah dijangkau.

Ekstensi tidak berfungsi di ponsel — di sana, gunakan situs web [videoner.download](https://videoner.download/id) atau bot [@VideonerBot](https://t.me/VideonerBot).
