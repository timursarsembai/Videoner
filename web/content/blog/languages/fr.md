Videoner est désormais disponible dans deux nouvelles langues : l’**ukrainien** et le **kazakh**.

## Où les nouvelles langues sont disponibles

- **Le bot** [@VideonerBot](https://t.me/VideonerBot) — tous les messages, les boutons et le menu des commandes.
- **Le site** — les versions ukrainienne et kazakhe de [videoner.download](https://videoner.download/fr), accessibles depuis le menu des langues.
- **L’extension de navigateur** — l’interface de la fenêtre et le bouton sur les pages vidéo.

Si votre Telegram ou votre navigateur est en ukrainien ou en kazakh, Videoner vous répondra automatiquement dans cette langue.

## Choisir la langue manuellement

Auparavant, le bot suivait la langue de votre Telegram. Désormais, vous pouvez choisir la langue vous-même :

1. Envoyez au bot la commande **/language**.
2. Choisissez une langue : Русский, Українська, Қазақша ou English.
3. Pour revenir au réglage par défaut, choisissez « Auto — comme dans Telegram ».

## La langue dans les groupes

Les administrateurs d’un groupe peuvent définir la langue des réponses du bot : **/settings → « Langue »**. Par défaut, dans un groupe, le bot répond à chaque membre dans la langue de son Telegram.

## La langue dans l’extension

La fenêtre de l’extension propose désormais un sélecteur de langue dans son en-tête. Les boutons sur les pages vidéo passent eux aussi dans la langue choisie. Mettez à jour l’extension depuis la [page de l’extension](https://videoner.download/fr/extension) si vous utilisez Chrome, Yandex Browser, Edge ou Opera — Firefox se met à jour tout seul.
