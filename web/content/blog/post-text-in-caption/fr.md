On transfère souvent une vidéo pour la légende de son auteur : une recette, une adresse, une blague, une liste de hashtags. Désormais, [@VideonerBot](https://t.me/VideonerBot) la conserve avec le fichier.

## Ce qui change dans la légende

Le titre de la vidéo est maintenant suivi du **texte de la publication**, tel que l’auteur l’a écrit. Cela fonctionne pour les publications des réseaux sociaux :

- TikTok ;
- Instagram ;
- Threads ;
- X (Twitter) ;
- Facebook ;
- Pinterest.

Sur YouTube, VK, Rutube et les autres plateformes d’hébergement vidéo, la description se compose généralement de liens et d’horodatages : le bot ne l’ajoute donc pas.

Si le titre de la publication n’est que le début de son texte, le bot ne le répète pas. Un texte long est raccourci : une légende Telegram ne peut pas dépasser 1024 caractères, et le lien vers la source doit rester intact.

## Dans les groupes

Le texte de la publication figure dans la légende complète. Si un administrateur du groupe a choisi dans /settings une légende courte (« titre et source ») ou aucune légende, le bot envoie les vidéos comme avant.

## La chaîne d’actualités sur le site et dans l’extension

Après un téléchargement sur [videoner.download](https://videoner.download/fr) et dans l’[extension de navigateur](https://videoner.download/fr/extension), un lien vers notre chaîne [@videonerdownload](https://t.me/videonerdownload) s’affiche désormais. Nous y annonçons chaque mise à jour.
