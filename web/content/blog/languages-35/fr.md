Videoner est désormais disponible en **35 langues**. 10 nouvelles langues s’ajoutent :

- **Africaines :** amharique — [/am](https://videoner.download/am), oromo — [/om](https://videoner.download/om), haoussa — [/ha](https://videoner.download/ha), somali — [/so](https://videoner.download/so)
- **Asie centrale et Caucase :** azerbaïdjanais — [/az](https://videoner.download/az), kirghiz — [/ky](https://videoner.download/ky), tadjik — [/tg](https://videoner.download/tg)
- **Asie du Sud-Est :** malais — [/ms](https://videoner.download/ms)
- **Européennes :** néerlandais — [/nl](https://videoner.download/nl), roumain — [/ro](https://videoner.download/ro)

## Ce qui est traduit

- **Le site** — toutes les pages, les articles du blog et les documents juridiques.
- **Le bot** — tous les messages, les boutons et le menu des commandes. Si votre Telegram est réglé sur l’une de ces langues, le bot vous répond automatiquement dans cette langue.
- **L’extension de navigateur** — la fenêtre de l’extension, le bouton « Télécharger » sur les pages vidéo et les messages d’erreur.

## Comment choisir la langue

- Sur le site — le sélecteur de langue dans le menu du haut.
- Dans le bot — `/language` ; dans un groupe — `/settings`.
- Dans l’extension — la liste des langues dans sa fenêtre.

Partout, les langues sont affichées dans le même ordre : selon le nom de chaque langue dans cette langue même.
